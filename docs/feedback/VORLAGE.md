# Reales Feedback erfassen

Leere Vorlage; keine Befragung durchgeführt. Nur benötigte Angaben erfassen, keine privaten Kontaktdaten oder unnötigen Klarnamen.

| Zeitpunkt | Rolle / anonymes Kürzel | Methode und Aufgabe | Tatsächliche Aussage oder Beobachtung | DR/NFR oder offener Klärungsbedarf | Issue | Änderung | Teststatus |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

Für NFR-1 fünf reale Personen ohne Hilfe ein Treffen finden und beitreten lassen. Dauer, Hilfestellungen und Abbruch je Person dokumentieren. Ziel: mindestens vier von fünf innerhalb von zwei Minuten. Erst nach Durchführung ein Ergebnis eintragen. Einwilligung und Aufbewahrung der Notizen vorher klären.
